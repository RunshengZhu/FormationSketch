# 舞阵 WuZhen · 队形编排

舞蹈队形编排 + 音乐对齐的纯 Web 双端应用。以 [ArrangeUs](https://arrangeus.app/) 功能为蓝本，针对**体育舞蹈队列舞**（男女舞对共同流动、可拆单人队形）特化。

**纯前端零依赖**：vanilla JS ES Modules + Canvas 2D + Web Audio + IndexedDB，无构建步骤、无账号、数据全部本地。

## 运行

```bash
cd formation-studio
python3 scripts/dev-server.py 8124 .   # 推荐（带 no-cache 头）
# 或: python3 -m http.server 8124
# 打开 http://localhost:8124
```

### 极简单文件版（即插即用）

```bash
npm run build:single   # 生成 dist/formation-studio.html（约 150 KB）
```

产物是把全部 HTML/CSS/JS 内联的**单个 HTML 文件**（约 150 KB）：手机/平板/桌面浏览器均可运行（响应式布局 + Pointer Events 统一鼠标触摸），数据存 IndexedDB，离线可用。

**项目文件格式 v2（含音乐）**：导出「项目文件 · 含音乐」会把音频以 base64 内嵌进 `.formation.json`——编舞与音乐打包成一个文件，分享/换设备后导入即恢复全部数据与音乐绑定，无需重新找音频。v1 旧文件（不含音乐）仍可导入。内嵌使文件体积约为音频的 1.33 倍（一首 5MB 音乐 → 约 6.7MB 文件）。移动端导出优先调起系统分享面板（可存文件/发微信/传云盘），桌面为直接下载。

**跨设备提示**：`file://` 直开在桌面 Chrome/Edge 完全可用，但 iOS Safari 对本地文件与 `file://` 的 IndexedDB 有限制——手机/平板建议通过任意静态托管（或网盘 HTML 直链）访问同一文件，或使用「添加到主屏幕」。

## 功能总览

- **项目库**：新建向导（舞对数/男女比例）、自动保存（IndexedDB）、复制/删除、导入导出 `.formation.json`
- **舞台**：米制坐标、网格+吸附、后台区、观众方向、中心线、背景图；平移/缩放（滚轮/双指）/视图复位
- **舞伴系统**（差异化核心）：
  - 配对舞者渲染为**单一菱形单元**（左半引带色+编号，右半跟随色+编号），命中/选择/拖拽以单元为单位；
  - **帧级组队呈示**：每个队形帧可独立切换「⛓ 组队（菱形）/ ⇱ 拆开（双圆+虚线）」，工具栏与属性面板均可操作；拆开后两人变独立圆点可单独编排，组回后收拢为菱形；
  - **帧间自动过渡动画**：组队帧→拆队帧自动播放"菱形打开、双人分离"动画；拆队帧→组队帧自动播放"双人汇聚、合为菱形"动画（由位置插值自然产生，无额外关键帧）；
  - 工具栏「⛓ 组对」「✂ 拆对」编辑名册配对关系；缺席舞者自动从上一队形顺延位置，全场 16 人始终可见；名册自动配对/按对重编号
- **队形编辑**：队形列表集中在左栏（缩略图 + 增删/复制/重排/↑↓，底部不再重复）、8 种队形生成器（横排/多排/纵列/圆/弧/V/斜线/菱形，支持"以舞对"或"单人"粒度、就近映射）、水平/垂直镜像（镜像自动交换舞伴位）、组旋转滑杆、等间距、两人换位、统一朝向（观众/圆心/舞伴）、朝向把手
- **Ghost 与路径**：前后队形虚影、当前→下一队形虚线路径
- **音乐对齐**：音频上传（波形）、BPM+点拍（Tap Tempo）、首拍偏移+试听、每小节拍数、块式时间线（hold/travel 块拖拽、节拍吸附、连续时长 Ripple）、小节/8拍刻度、**⇤ 对齐到播放头**（把当前队形块起点精确对齐到时间轴任意时间戳，自动调整前一段过渡时长）
- **时间轴时长独立可调**：每个队形的"保持时长/过渡时长"可在属性面板直接输入数值（也可在时间线拖块边缘），过渡越长变换越慢，随音乐回放生效
- **切帧动效（纯舞台动画，与时间轴完全无关）**：手动切换队形帧（缩略图/时间线/⏮⏭）时，舞台播放约 0.7 秒的快速过渡动画——不经过播放引擎、不移动播放头、不触碰时间线任何状态；动效中操作会立即跳到终态不吞输入；**动线编排靠插入中间队形帧表达**——新建队形总是插入当前帧之后并立即播放动效
- **编辑开关（默认开）**：舞台工具栏「✏ 编辑」或 E 键切换。开启：舞台始终可拖动编辑（与播放头位置无关）；关闭：查看模式，舞台跟随时间轴播放头对位预览（只读）。真实播放期间舞台临时显示回放画面
- **导出**：当前队形 PNG、打印/PDF（每队形一页含备注与小节标注）、项目 JSON
- **体验**：撤销/重做、快捷键（空格播放、E 编辑开关、D 新队形、G 吸附、F 面向观众、方向键微调、Del 移出队形）、移动端四 Tab 布局（队形/舞台/音乐/更多）、页面隐藏时立即落盘
