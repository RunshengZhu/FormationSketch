# 音乐剪辑 UI/操作规格 v3（展开态对齐 Adobe Audition 多轨体验）

> 常规编辑模式：tag 道 + 音频轨**简单态**（26px 常驻）不变。
> **展开态重构为「Audition Lite」单轨多轨体验**：clip=可自由摆放的独立对象（允许间隙/重叠自动交叉淡化）、
> trim=内容锚定的 Audition 式语义、音轨表头、时间选区、右键菜单、键盘微调。
> 交互做减法的是「简单态」；展开态做加法——对齐专业 DAW 的肌肉记忆。

## 1. 展开态布局

```
┌──────────┬─────────────────────────────────────────────┐
│ 音轨表头  │  尺规（拍/秒双刻度 + scrub + 时间选区拖拽）   │
│ (120px   ├─────────────────────────────────────────────┤
│ 固定宽)  │  tag 道                          h=18px     │
│ ──────── │─────────────────────────────────────────────│
│ 资产名    │  ★ 音频轨（Audition Lite）        h=72px    │
│ 时长      │   [clip 甲 ~~~~ fades] [clip 乙 ~~~~]       │
│ 音量滑杆  │   （可自由摆放：间隙=静音，重叠=自动交叉淡化）│
│ 🔇 静音   │─────────────────────────────────────────────│
│ ⌄ 收起   │  队形块区（既有）                            │
└──────────┴─────────────────────────────────────────────┘
底部左下：－/＋/⤢ 横向缩放（锚定光标，Alt+滚轮同义）
```

- 音轨表头（展开态独有，120px 固定）：资产名、时长、音量迷你滑杆、静音 🔇、⌄ 收起。
- 简单态（26px）仍为默认；展开态记忆（localStorage）。
- 注记（R41 reviewer）：键盘 **End 键 = min(totalBeats, lastClipEnd)** 的秒位——时间轴总长与最后 clip
  终点取小者：clip 全在时间轴内则跳最后 clip 终点；clip 越出时间轴（长音频尾）则钳在时间轴末端
  （与 §7 播放终态/末 clip 终点先到的混合语义一致）。

## 2. Clip 模型（关键变化：从「分段」到「独立对象」）

```
clip = { id, assetId, timelineStartSec, srcStartSec, lengthSec,
         fadeInSec, fadeOutSec, gain, name, color? }
```

- **自由摆放**：clips 可有间隙（=该区间静音）；
- **重叠 = 自动等功率交叉淡化**（lightmix 既有能力；重叠区波形按淡化包络收窄，交叠中点显菱形手柄可调）；磁吸关闭时允许精确重叠；
- **每 clip 独立**：可拆（Ctrl/Cmd+K / 剃刀点击）、可拖到任意位置、可 trim 出任意源区间——不再有「段 N」序号语义，clip 名默认=资产名+序号，可改名。

## 3. 原子操作（Audition 对齐，18 个）

| # | 操作 | Audition 对齐语义 | 入口/手势 |
|---|---|---|---|
| C1 | 选择 clip | 单击=选中（高亮描边）；**Ctrl/Cmd+单击=多选**；双击空白=取消全选；空白拖拽=**时间选区**（蓝色高亮带） | 左键 |
| C2 | 移动 clip | 拖 clip 任意处（水平；磁吸开启时吸附） | 拖拽 |
| C3 | 微调 | 选中后 ←/→ 逐帧微移；Shift+←/→ 按网格步进 | 键盘 |
| C4 | **trim 左缘（Audition 式）** | 拖左缘红括号光标：**srcStart 与 timelineStart 同步前进**（露出/隐藏更多源内容，内容锚定源时间）；Shift+拖=只改边界（老语义） | 拖缘（trim 光标） |
| C5 | trim 右缘 | 拖右缘：length 变化（源锚定）；Shift+拖同上 | 拖缘 |
| C6 | 分割 | 播放头处 **Ctrl/Cmd+K**；或剃刀模式点 clip（工具条剃刀图标 R） | 快捷键/剃刀 |
| C7 | 淡入/淡出 | clip 顶部方 handle 横拖（capFades）；重叠自动等功率交叉淡化，菱形手柄调比例 | 拖 handle/菱形 |
| C8 | 增益包络 | clip 中线黄色横线拖动（波形同步缩放） | 拖横线 |
| C9 | 静音 clip | 选中 + 右键「静音」（波形置灰，播放跳过） | 右键菜单 |
| C10 | 删除 | Delete/Backspace（选中）；右键「删除」；**波纹删除**（右键子项：删后右侧 clip 左移补位） | 键/右键 |
| C11 | 时间选区 | 尺规拖拽=蓝色时间选区（播放限制在选区=临时循环；可作为 trim/删除的作用域） | 尺规拖拽 |
| C12 | 播放头 | 单击尺规/音轨=移动；双击 clip=选中并循环播放该 clip（预览） | 单击/双击 |
| C13 | 导入到落点 | 从媒体库拖资产名到音轨=在落点生成 clip；拖音频文件入音轨=导入+落点 | 拖放 |
| C14 | clip 重命名/换色 | 右键「重命名/颜色」 | 右键 |
| C15 | 音轨静音/音量 | 表头 🔇 / 音量滑杆 | 表头 |
| C16 | 缩放 | －/＋/⤢（左下）+ **Alt+滚轮锚定光标缩放** + Shift+滚轮横移 | 滚轮/按钮 |
| C17 | 磁吸 | 磁铁图标 / S（hover 音轨时）；候选=clip 缘/块边界/tag/播放头/时间选区/零交叉 | 图标/键 |
| C18 | dropbox 联动 | 「按队形段自动切」结果=一组自由 clip（可继续逐个微调——比 v2 的刚性分段更强） | 主行按钮 |

## 4. 右键菜单（clip 上）

```
分割于播放头(K) ｜ 修剪到时间选区 ｜ 静音/取消静音 ｜ 波纹删除 ｜ 删除
──────────
重命名 ｜ 颜色 ▸ ｜ 增益重置
```
空白处右键=粘贴/全选（v1 只放「取消选择」）。

## 5. 键盘映射（展开态）

| 键 | 语义 |
|---|---|
| Space | 播放/暂停（既有） |
| Ctrl/Cmd+K | 分割播放头处选中 clip |
| ←/→（+Shift） | 微移选中 clip（网格步进） |
| Home/End | 播放头回 0 / 跳最后 clip 终点 |
| Delete/Backspace | 删选中 clip |
| S（hover 音轨） | 磁吸开关 |
| R | 剃刀模式开关 |
| Esc | 取消选择/退出剃刀 |

## 6. 守卫与状态（不变项）

- 编辑锁=全部编辑禁用（选择/预览可用）；播放中 trim/分割/移动/删除先自动暂停；淡化/选择/静音可实时；
- 双时钟：clips 区间调度+段间静音+自动交叉淡化；音频结束/虚拟接管沿用 #7；
- file://：clips 参数持久（LS），资产 blob 不持久（明示）；
- 400ms 防抖窗口语义不变（D-15）。

## 7. 与队形编排的联动（不变 + 增强）

- 按队形段自动切（C18 家族）：块边界→分割点，段间自动交叉淡化=过渡拍；
- 磁吸候选含块边界与 tag；
- **新增**：块边界变动（拖块边）时，若 clip 缘吸附在旧边界 → 提示「跟随移动」（一次性选择，可全局默认开）；
- 段长↔拍数徽标沿用。

## 8. 验收基线（IR-C1~C10）

| 用例 | 断言要点 |
|---|---|
| IR-C1 展开态布局 | 表头 120px+音轨 72px、资产信息、静音/音量生效 |
| IR-C2 选择模型 | 单选/Ctrl 多选/空白取消/空白时间选区 |
| IR-C3 自由摆放与交叉淡化 | 两 clip 重叠→自动等功率淡化+菱形手柄；拖开还原 |
| IR-C4 Audition trim | 左缘拖动 srcStart/timelineStart 同步（源内容锚定）；Shift 变体 |
| IR-C5 分割 | Ctrl+K 与剃刀两路径；分割点两侧独立可拖 |
| IR-C6 淡化与增益 | fade handle/增益横线/波形同步 |
| IR-C7 波纹删除/静音 | 波纹后右侧左移补位；静音 clip 播放跳过 |
| IR-C8 时间选区 | 选区拖拽/播放限制/作为删除作用域 |
| IR-C9 磁吸与键盘 | 候选吸附/微调/Home/End/R/Esc |
| IR-C10 守卫矩阵 | 编辑锁/播放中先暂停/双时钟终态 V12 复测 |
