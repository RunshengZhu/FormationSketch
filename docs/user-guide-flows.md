**版本基准：build-24-skill / v0.9.13（2026-09-14）** · HEAD `99861fa`
实测基准：dev 源码树 `http://localhost:8137/`（Playwright 实测，与在线入口 build 徽标一致）＋在线入口 `http://59.110.90.21:8321/apps/wuzhen/`（实测 build 徽标 `build-24-skill`）。

**面向读者**：舞蹈老师 / 创作人（功能与动线部分）、排练助手（现场演示动线）、以及后续编写 E2E 的工程同学（每条动线附「边界与异常清单」和「建议 E2E 用例」）。

### 2.1 舞台手势（桌面鼠标/键盘 vs 触摸/笔）

| 意图 | 桌面 | 触摸 / 笔 |

| 框选 | 空白左键拖动（<6px 视为点击=清空选择） | 笔/触屏：**长按空白 0.5s**（起点出圆点标记）后拖动，松手结算 |
| 移动舞者 | 按住拖动（网格吸附；拖到他人身上松手或**驻留 1.5s** 弹合并确认浮窗） | 同左 |

| 上下文菜单（未合并舞者=删除；多选中=整选择菜单） | 右键舞者 | 长按舞者 |
| 平移 | 中键拖动，或 **空格+左键拖动**；横向滚轮/触控板横滑 | 空白处拖动（未移动抬起=点按清空选择） |
| 缩放 | 滚轮 / 触控板捏合（以指针为中心） | **双指捏合**（进行中的拖动立即回滚，不产生历史） |
| 取消当前手势 | Escape（拖动中=回滚到按下前，不产生历史）；双指中断同回滚 | 同左（系统接管 pointercancel 时同样安全回滚） |
| 朝向调整 | 选中单人拖朝向把手（样式页开关）；或属性面板直接输角度 | 同左 |
| 队形列表重排 | 拖拽 chip（HTML5 拖放） | **长按 chip 0.3s 拿起**，拖到目标位（贴近列表边缘自动滚动，有触觉反馈） |
| 时间轴 | 点击/拖尺规=播放头定位；拖块边缘=调时长（吸附整拍）；Ctrl+滚轮=缩放 | 同左（时间轴画布已禁浏览器滚动接管） |

## 3. 典型使用动线（按「角色 × 场景」）

> 角色假设：
> - **编舞老师**：主要创作者，负责建档、排队形、配音乐、定稿分发。
> - **排练助手**：现场操作播放/切页/循环，不改编舞内容。
> - **接手老师**：拿到别人（或 skill）产出的项目文件/链接，需要打开、理解、修改。

用例编号规则：`E2E-S<场景>-<序号>`，每格注明断言类型：**DOM**（选择器/文案）、**状态**（`window.__fs.snapshot()` / store 状态）、**像素**（canvas/截图对比）。

### 场景 1 · 编舞老师：从零开始编队形

#### 动线 1.1 建档：从空白到第一份项目
【角色】编舞老师
【前置状态】任意渠道打开应用，处于项目库（首次使用为空库，显示「还没有项目，点击右上角「新建项目」开始编排队形」）。
【步骤】
1. 点「**＋ 新建项目**」→ 弹窗「新建项目」。
2. 填「项目名称」；选「初始方案」：标准 6 对（独立）/ 6 对 · 已组合（建档即两两合并为胶囊单元）/ 8 对 · 已组合 / 自定义（「对数（男女各半）」仅自定义可编辑）。
3. 按需填「额外男舞者」「额外女舞者」；「初始编组」选「男士 / 女士」或「不分组」。
4. 点「**创建**」→ 直接进入编辑器，自动生成「开场队形」（双横排，全部面向观众方向）。
5. 界面导览：左栏队形缩略图列表、中间舞台画布（上方一排舞台工具）、右侧四个属性页签「**队形 / 舞台 / 样式 / 编组**」、底部播放条＋「🎵 音乐与节拍」时间轴；窄屏（≤1023px）时底部变为「**队形 / 舞台 / 更多**」三 Tab（默认「舞台」），音乐面板默认收起。
【数据流】建档即写入存储（在线=IndexedDB `formation-studio` 库 projects 表；下载=localStorage `wuzhen:proj:*`），此后每次改动 400ms 自动落盘。项目 id 记入 `fs.lastProject`，下次打开自动恢复。
【边界与异常】
- 空库直接新建（历史 P0 回归：创建失败）；
- 对数 0 或 30 上限（输入钳制 0..30）；0 人项目进入编辑器后名册为空提示「名单为空：点「＋ 单人」添加舞者。」；
- 「已组合」方案在编辑器中拖开两成员 >0.8m 后呈示为两圆＋虚线（拆分呈示），拖回 ≤0.8m 自动合回徽标；
- 弹窗「关闭」=放弃建档。
【建议 E2E 用例】

| 编号 | 操作 | 断言点 |
|---|---|---|
| E2E-S1-01 | 空库 → 「＋ 新建项目」→「创建」 | 状态：进入 editor，`snapshot().dancers=12`（6 对默认）；DOM：`#build-tag`=build-24-skill |
| E2E-S1-02 | 选「6 对 · 已组合」建档 | 状态：`formations[0].merges` 长度=6 且 style=capsule；像素：舞台出现 6 个胶囊徽标 |
| E2E-S1-03 | 选「自定义」改对数=0 + 初始编组「不分组」 | 状态：dancers=0、groups=0；DOM：名册空态提示文案 |
| E2E-S1-04 | 预设非自定义时「对数」输入框 disabled；切回自定义恢复 | DOM：`input:disabled` 切换 |
| E2E-S1-05 | 建档后刷新页面 | 状态：自动恢复上次项目（`fs.lastProject`）；视图仍在编辑器 |
| E2E-S1-06 | 弹窗「关闭」取消 | 状态：库列表仍为空，无新项目 |

#### 动线 1.2 逐段排队形：生成 → 微调 → 合并 → 插帧
【角色】编舞老师
【前置状态】已进入编辑器，名册就绪。
【步骤】
1. 选「**生成队形…**」一种（如「圆形」），必要时把「编队粒度」换成「仅男士/仅女士」——生成会整体替换当前队形（缺席者从上一帧顺延位置）。
2. 框选/多选若干人：桌面空白拖动框选；触屏开「**☰ 多选**」后逐个点按。
3. 微调：拖动（自动吸附网格）、方向键微调、右面板逐人改「朝向」角度、选中单人拖朝向把手。
4. 整形工具：「**⇋ / ⇅**」镜像、「**⟳**」旋转滑杆、「**均布**」（≥3 人；右键切横向/纵向）、「**换位**」（恰 2 个单元）、「朝向…→ 面向观众/面向圆心」。
5. 合并单元：选恰好 2 人 →「**合并为单元**」（默认胶囊）；或直接把 A 拖到 B 上（松手或停 1.5s）→ 浮窗选「胶囊 / 单编号」。要拆开：双击/长按单元 →「**✂ 拆开**」。
6. 下一段队形：「**＋ 新队形**」（或键盘 D、索引条「＋」）——新帧复制当前队形插到其后并自动播 0.7s 切帧动画；在新帧上重复 1–5。动线变化靠插入中间帧表达。
7. 顺序调整：左栏拖拽缩略图；或右面板「**↑ 上移 / ↓ 下移**」。
【数据流】全部改动走 mutate→commit（可撤销），自动落盘；合并记录（merges）是**帧级**数据，只存在于操作时的那个队形帧。
【边界与异常】
- 「均布」<3 人 toast「请先框选至少 3 名舞者」；「换位」非 2 单元 toast「请选中两个单元（合并单元或单人）」；「合并为单元」非 2 人 toast「请先选中恰好 2 名舞者」/已是单元 toast「所选两人已是一个单元」；
- 一名舞者再与他人合并时**旧单元被静默解除**（替换语义）；
- 至少保留一个队形：删除最后一个队形被拒（toast「至少保留一个队形」）；
- 生成器不感知当前选择（按全队/性别组落位）；
- 拖动进行中按 Escape/来第二指=整单元回滚、不产生历史。
【建议 E2E 用例】

| 编号 | 操作 | 断言点 |
|---|---|---|
| E2E-S1-07 | 生成器「圆形」 | 状态：positions 全部到圆轨道（半径/圆心容差）；像素：缩略图更新 |
| E2E-S1-08 | 粒度「仅男士」生成 | 状态：仅 M 角色位置改变，F 不动 |
| E2E-S1-09 | 框选 3 人→「均布」；右键「均布」 | 状态：3 人等距；toast「均布方向：横向/纵向（右键切换）」 |
| E2E-S1-10 | 拖 A 到 B 驻留 1.5s → 浮窗「胶囊」 | 状态：merges+1、两点重合；DOM：浮窗按钮「胶囊/单编号」 |
| E2E-S1-11 | 对已是单元的成员再与他人合并 | 状态：旧 merge 消失、新 merge 存在（替换语义） |
| E2E-S1-12 | 拖动中按 Escape | 状态：位置回到按下前、历史栈不变长 |
| E2E-S1-13 | 「＋ 新队形」 | 状态：formations+1、新帧 positions=上一帧克隆、选中清空；像素：切帧动画后终态=新帧 |
| E2E-S1-14 | 删除唯一队形 | DOM：toast「至少保留一个队形」；状态：formations 不变 |

#### 动线 1.3 名册与显示定制
【角色】编舞老师
【前置状态】编辑器内。
【步骤】
1. 顶栏「**名册**」→「**名册 · 舞者与编组**」：逐行改姓名/简称/角色/颜色；「**＋ 单人**」补人（自动出现在所有队形）；「**重编号码**」按顺序重编简称。
2. 编组：「＋ 存为编组」（先在舞台选中一批人）或名册里点行的编组芯片加入/移出。
3. 显示字段：右面板「舞台」页「**显示字段**」→ 编号序号/简称/姓名。
4. 删人：名册行「删除」→ confirm「删除舞者「X」？（将从所有队形移除）」。
【数据流】名册属项目数据，随项目落盘；labelMode 存 `project.settings.labelMode`（随导出携带）。
【边界与异常】删人联动清理：其编组成员资格、所有帧的 merges、所有帧的 positions 一并移除；改角色会重置为角色默认色，改颜色不会；姓名超长在画布截断为「3 字+…」。
【建议 E2E 用例】

| 编号 | 操作 | 断言点 |
|---|---|---|
| E2E-S1-15 | 改名 +「显示字段=姓名」 | 状态：settings.labelMode='name'；像素：舞台圆内显示新名（截断） |
| E2E-S1-16 | 「重编号码」 | 状态：short 按名册序=1..N；像素：标签变数字 |
| E2E-S1-17 | 删除某舞者 | 状态：dancers-1、所有帧 positions/merges/groups 引用清零 |
| E2E-S1-18 | 「＋ 单人」 | 状态：新舞者出现在所有既有队形（ensureDancerInFormation） |
| E2E-S1-19 | 舞台选 3 人 →「＋ 存为编组」 | 状态：groups+1；DOM：编组页新行「选择/重命名/删除」 |
| E2E-S1-20 | 名册芯片移出/加入 | 状态：memberIds 增减；芯片 class `chip-on` 切换 |

### 场景 2 · 编舞老师：给已有队形做编辑修改（含接手他人作品）

#### 动线 2.1 打开既有项目做局部调整
【角色】编舞老师 / 接手老师
【前置状态】项目已在库中（或经动线 5.1/5.2 导入）。
【步骤】
1. 库页点卡片打开（或右键「**打开**」）。
2. 改某队形：索引条/左栏 chip 选中该帧 → 直接拖/生成器/镜像等（操作只影响当前帧）。
3. 插一个队形：选中参照帧 →「**＋ 新队形**」（复制当前帧插其后）。
4. 改时长：块时长栏「保持 −/＋」「过渡 −/＋」，或右面板「时间轴时长（拍）」直接输数，或时间轴拖块边缘。
5. 换合并：单元浮窗「**✂ 拆开**」/样式切换（胶囊↔单编号）/重新「**合并为单元**」——只影响当前帧。
6. 其余帧不动；不满意一步「**↺**」。
【数据流】同一自动保存通道；重排队形时各帧时长按队形 id 跟随移动（不串位）。
【边界与异常】切换队形帧会清空当前选择（含多选）；播放中切帧/删队形/重排都会先暂停播放；「对齐到播放头」对第 1 个队形无效（toast「第一个队形从 0 拍开始，无需对齐」）。
【建议 E2E 用例】

| 编号 | 操作 | 断言点 |
|---|---|---|
| E2E-S2-01 | 开项目改第 3 帧两处 | 状态：仅第 3 帧 positions 变化，其余帧逐字节不变 |
| E2E-S2-02 | 第 2 帧后插入新队形 | 状态：插入位=index+1（非尾部）；blocks 按 formationId 保留时长 |
| E2E-S2-03 | 拖块边缘改 hold 16→20 | 状态：blocks[i].holdBeats=20 且吸附整拍；历史恰 1 条「调整时长」 |
| E2E-S2-04 | ripple 开/关两种模式下拖 hold | 状态：开=后续块整体右移；关=自身过渡被压缩、后续块不动 |
| E2E-S2-05 | 切换帧 | 状态：selection 清空 |
| E2E-S2-06 | 播放中删队形 | 状态：player.playing=false（先暂停）；无报错；时间轴块数-1 |
| E2E-S2-07 | 播放中拖拽重排队形（触摸长按） | 状态：先暂停；顺序更新且时长随队形走 |

#### 动线 2.2 撤销安全网（误操作兜底）
【角色】全体
【步骤】任何改动后：「**↺**」撤销、「**↻**」重做；撤销粒度=一次提交（拖动=松手一条、生成器一条、重命名一条…）。
【数据流】撤销栈=项目 JSON 快照，最多 60 步，超出丢弃最旧。
【边界与异常】重命名后撤销应恢复旧名；撤销到「打开项目」初始态后 ↺ 变灰；打开/新建/导入会清空撤销栈（不能跨项目撤销）；自动保存保存的是**当前**状态（撤销也会落盘）。
【建议 E2E 用例】

| 编号 | 操作 | 断言点 |
|---|---|---|
| E2E-S2-08 | 连续 5 类操作后逐级 undo | 状态：每级回到前一快照；`canUndo/canRedo` 正确 |
| E2E-S2-09 | 重命名项目→undo | 状态：`meta.title` 恢复 |
| E2E-S2-10 | 撤销到栈底 | DOM：↺ disabled（opacity 0.4） |
| E2E-S2-11 | undo 后刷新页面 | 状态：落盘为撤销后的状态 |
| E2E-S2-12 | 65 次提交后 undo 到底 | 状态：栈深 60，最早操作不可撤销 |

#### 动线 2.3 接手他人的项目文件直接修改
见动线 5.1（文件导入）——导入后按动线 2.1 操作即可。注意导入总是生成「标题（副本）」的新项目，不会覆盖本地同名项目。
【角色】接手老师
【前置状态】拿到他人导出的 `.formation.json`。
【步骤】「**导出 ▾**」→「**导入项目文件…**」→ 进入「原名（副本）」→ 按动线 2.1 做局部调整 → 自己的设备上它与本地项目互不干扰。
【数据流】新 id 新记录，源文件不动。
【边界与异常】源文件里可能有本项目从未出现过的数据形态（旧版本 v1、diamond 单元样式）——载入时自动清洗迁移（diamond/twin→胶囊），不破坏编辑。

| 编号 | 操作 | 断言点 |
|---|---|---|
| E2E-S2-13 | 导入多帧多合并项目 | 状态：逐帧 positions/merges 与源 JSON 一致（往返无损） |
| E2E-S2-14 | 在导入副本上改一帧 | 状态：仅该帧变化，其余帧逐字节不变 |
| E2E-S2-15 | 同一文件导入两次 | 状态：库中两个独立「（副本）」项目，互不覆盖 |

### 场景 3 · 排练助手：排练现场演示

#### 动线 3.1 演示准备：上编辑锁
【角色】排练助手
【前置状态】设备已打开该项目（大屏电脑或手机）。
【步骤】
1. 点工具栏「**✏ 编辑**」关闭编辑（按钮高亮消失）——舞台进入查看模式：只读、随播放头对位，任何拖动都改不了队形。
2.（可选）关「**幽灵**」「**路径**」让画面更干净；「**⤢**」复位视图。
【数据流】编辑锁、幽灵、路径是界面开关（不进项目文件）；页面刷新后编辑锁回默认「开」。
【边界与异常】**查看模式下触摸端舞台手势全部禁用**（拖动/平移/捏合缩放/长按菜单都不响应，舞台跟随播放头）；桌面滚轮缩放仍可用。E 键也会切编辑锁——现场注意键盘误触。
【建议 E2E 用例】

| 编号 | 操作 | 断言点 |
|---|---|---|
| E2E-S3-01 | 关「✏ 编辑」后拖舞者 | 状态：positions 零变化、无历史；DOM：按钮无 `toggled-on` |
| E2E-S3-02 | 查看模式下触摸平移/捏合 | 状态：view.ox/oy、scale 不变（手势被拒） |
| E2E-S3-03 | 查看模式按 E 键恢复编辑 | 状态：editMode=true，舞台恢复可拖 |
| E2E-S3-04 | 编辑模式播放中尝试拖舞者 | 状态：positions 零变化（播放期间只读） |

#### 动线 3.2 现场播放操作
【角色】排练助手
【步骤】
1. 播放：「**▶**」（空格）——有音乐按音乐时钟，无音乐按虚拟时钟，两档都播完整条时间轴（终态统一：停在末拍并置结束）；设了「**数拍入场**」则全屏倒数后起播，数拍中再按 ▶/空格或 Esc=取消倒计。
2. 暂停/停止：「**⏸**」（再按 ▶ 续播）/「**⏹**」回 0。
3. 切队形：「**⏮ / ⏭**」、点索引条 chip、点时间轴块——切帧即暂停（播放中按这些键会先停）。
4. 循环某段：选中目标队形帧 → 勾「**循环**」→ 播放，在「该队形保持+过渡」区间内打转。
5. 节拍器：勾「**节拍器**」（🎵 音乐与节拍主行），每拍一声、小节首拍高音。
6. 快速跳时间点：时间轴尺规上点击/拖动（scrub）。
7. 变速：「**速度**」0.5×–2×（音频同步变速）。
【数据流】播放是纯现场行为，不改项目数据（节拍器勾选会存进项目）。
【边界与异常】切帧预览动画期间循环被挂起、结束自动恢复；播放结束自动停——有无音乐终态已统一（都停在时间轴末拍并置结束）；无音乐 ▶ 也播完整条时间轴（不再单段即停）；音频比时间轴短时音频放完即停、播放头停在音频末拍并 toast「音乐已结束」，再按 ▶ 从当前拍以虚拟时钟走完剩余段；循环勾选时切帧，循环区间跟随新帧。
【建议 E2E 用例】

| 编号 | 操作 | 断言点 |
|---|---|---|
| E2E-S3-05 | ▶ 起播（无音乐） | 状态：playing=true、beat 前进；DOM：▶ 变 ⏸ |
| E2E-S3-06 | 数拍入场=4 起播 | DOM：`#countin-overlay` 依次 4→1→隐藏；状态：beat 从 0 起播 |
| E2E-S3-07 | 播放中点 ⏭ | 状态：先暂停；formationIndex+1、播放头跳到该帧 holdStart |
| E2E-S3-08 | 勾循环播一个段 | 状态：beat 在 [holdStart,travelEnd] 内回绕 ≥2 次 |
| E2E-S3-09 | 节拍器播放 | 状态：`timeline.metronome=true` 且随项目保存；（音频断言可豁免，验证状态位即可） |
| E2E-S3-10 | 尺规 scrub 到 8.2 处 | 状态：player.beat≈对应值；播放头红线像素位置≈x |
| E2E-S3-11 | 速度 0.5× | 状态：setRate 生效（音频）；虚拟时钟下 beat 增速减半 |
| E2E-S3-12 | 播到队形末尾自动停 | 状态：playing=false、beat=该段 travelEnd |

#### 动线 3.3 手机/平板现场演示
【角色】排练助手
【前置状态】手机浏览器打开在线入口（或已装主屏的 PWA——需 HTTPS 渠道）。
【步骤】

### 场景 4 · 编舞老师：音乐适配（真实音乐对齐）

#### 动线 4.1 标定 BPM 与首拍
【前置状态】项目已打开，拿到比赛音乐文件。
【步骤】
1. 「**🎵 音乐与节拍**」→「**载入音乐…**」选音频——波形出现在时间轴并保持显示。
2. 「**BPM**」（主行）：直接输，或展开「**校准 ▸**」边听音乐点「**点拍**」（连点 3 次出值，取最近 8 次平均，停 2.5s 重新起算）。播放中 BPM/首拍/点拍锁定（暂停后可修改）。
3. 「**首拍**」（主行）：填音乐里第一拍所在的秒数；展开校准点「**试听**」——从首拍前 2 秒播 4.5 秒，听鼓点是否与时间轴小节线对齐，不对就微调重试。首拍 ≥ 音频时长会 toast 告警（不阻断）。
4. 校准子行：「**小节**」按音乐选 4/3/2/6 拍；「**数拍入场**」设给舞者的预备拍数。
【数据流】BPM/首拍/小节/数拍全部存项目；音频文件本身存 IndexedDB（在线）。改 BPM 会等比改变整条时间轴的秒长。
【边界与异常】BPM 钳制 30–300（非法输入回退 120）；「试听」未载入音乐 toast「请先载入音乐」；音频格式浏览器不支持 → toast「音频无法播放，已忽略」（旧音乐保留、项目可继续编辑）；播放中 BPM/首拍输入禁用（title「暂停后可修改」，程序化改动同样被拦截）；**BPM/首拍标错=整条时间轴错位**，且无自动检测（诚实限制）。
【恒定 BPM 假设（round46 显性化）】拍↔秒换算仅在**全曲恒定 BPM** 时成立：现场版/渐快渐慢/多段 BPM 曲下，拍线、tag、块边界、节拍器、数拍随时间线性漂移，且**无法靠调单值 BPM 救回**（两段各自仍偏）。降级路径：① 载入音频时若实际时长与拍模型（首拍+总拍数×拍长）偏差 >10% → 一次性 toast「音频节奏与拍线可能不一致（变速曲），可用秒刻度对齐」（同一标签页会话只提示一次，sessionStorage 记忆已读；新开会话最多再提示一次）；② 尺规切「**秒刻度**」按秒看；③ **Alt+←/→** 播放头秒步进 ±0.5s 按秒对位；④ 或在应用外先把变速曲恒速化再载入。
【建议 E2E 用例】

| 编号 | 操作 | 断言点 |
|---|---|---|
| E2E-S4-01 | 载入 wav（tests/fixtures/click120.wav） | 状态：audio.ready=true、duration>0；DOM：文件名入「#audio-name」；像素：波形出现 |
| E2E-S4-02 | BPM 输 999 | 状态：钳到 300；输 0 → 回退 120 |
| E2E-S4-03 | 点拍 4 次（间隔 500ms） | 状态：BPM≈120 |
| E2E-S4-04 | 点拍间隔 >2.5s 后再点 | 状态：计数重置（不掺旧样本） |
| E2E-S4-05 | 「试听」无音乐 | DOM：toast「请先载入音乐」 |
| E2E-S4-06 | 首拍=2.5 试听 | 状态：从 0.5s 起播约 4.5s 自动暂停 |

#### 动线 4.2 段落对齐（队形块贴合音乐段落）
【前置状态】音乐已标定，队形序列已排好。
【步骤】
1. 逐块调时长：块时长栏「**保持 −/＋**」「**过渡 −/＋**」（±1 拍），或右面板直接输拍数（0.5–999），或时间轴拖块边缘（自动吸整拍）。
2. 「**连续时长**」（默认开，校准 ▸ 子行）：改某块保持时长，后续块顺延；取消勾选则压缩自身过渡、后续不动。
3. 精确对点：把播放头 scrub 到音乐段落起点（如副歌第 1 拍）→ 选中目标队形 →「**⇤ 对齐到播放头**」——自动拉长/压缩前一段过渡。不可达时 toast 给出实际可达位置。
4. 核对：块时长栏显示「（1.1 起 · 共 X.Xs）」总时长；播放全曲走一遍。
【数据流】blocks 随项目保存；总拍数=Σ(保持+过渡)，秒数=BPM 换算。
【边界与异常】只有 1 个队形时无「过渡」行（UI 隐藏）；块最小 0.5 拍、最大 999 拍；极多块（50+）时时间轴自适应缩小、索引条横向滚动；「对齐到播放头」会改**前一段**的 travelBeats（必要时压缩其 holdBeats 至 0.5 下限）。

### 场景 6 · 任何人：离线 / 弱网赛场

### 场景 7 · 编舞老师 × 辅助创作（dancesport-choreo skill）

#### 动线 7.1 候选 → 预览 → 体检 → 回填循环
【角色】编舞老师 + AI 辅助（agent 侧装 dancesport-choreo skill）。
【原则】**人在回路**：app 是唯一事实源；agent 只出「候选 2–4 个 + SVG 图 + 量化属性」，选哪个、好不好看永远由老师拍板；每次 apply 存版本快照，禁止一次性生成整支舞。

## 4. 已知限制与提示（诚实清单）

1. **下载版配乐不持久**：file:// 下载版音乐只在当前会话有效（localStorage 装不下音频），重开需重选；要音乐跟项目走，用「项目文件 · 含音乐」导出/导入。
2. **Safari 编组快捷键**：Cmd+1..9 被浏览器保留切标签页，事件不到页面——Safari 一律用右面板「编组」页「选择」按钮（应用内画布提示与编组面板提示均已写明，实测一致）。Chrome/Edge 的 Ctrl/Cmd+1..9 页面侧生效。
3. **iOS Safari「7 天清理」**：普通网页的本地数据 7 天不访问可能被系统清掉；「添加到主屏幕」可豁免。重要项目请定期导出 JSON。
4. **离线能力需 HTTPS**：SW 断网缓存只在 HTTPS（或 localhost）托管下生效；**当前在线入口为 HTTP，实测无 Service Worker，断网打不开**。下载版不依赖网络但受限于第 1/3 条。
5. **BPM 需手动标定，且假设全曲恒定**：无自动节拍检测；点拍+首拍试听是唯一校准手段，标错则整条时间轴错位。**恒定 BPM 假设**：变速曲（现场版/渐快渐慢/多段 BPM）下拍线/tag/块边界/节拍器随时间漂移且无法靠单值 BPM 救回——降级路径：载入体检 toast（偏差 >10% 一次性提示）→ 尺规切「秒刻度」→ Alt+←/→ 播放头秒步进 ±0.5s（或应用外恒速化后再载入）。实证数字见 docs/music-editing-defects.md round46 附表。
6. **切帧预览 ≠ 时间轴**：0.7s 切帧动画是纯界面效果，不改变任何时长数据；真正的变换快慢由「过渡」拍数决定。
7. **编组 ≠ 合并**：编组只是快速选择辅助（删组不删人）；合并单元是帧级呈示/操作单元（拖动、拆开以整单元为原子）。两者可叠加。
8. **真机确认清单**：iOS/Android 真机的长按放大镜、左缘返回手势、下拉刷新、触控板横滑历史导航等系统级行为，维持人工确认清单（tests/ux-browser-conflicts.md §12，M-1..M-8），自动化未覆盖。
9. **README 与实况的差异（本轮核对发现，待文档同步）**：① README 写「移动端四 Tab（队形/舞台/音乐/更多）」，实测为**三 Tab**（队形/舞台/更多），音乐在底部「🎵 音乐与节拍」折叠面板；② README 的「⛓ 组对 / ✂ 拆对」按钮已不存在，现行文案为「合并为单元 / 取消合并」（浮窗「✂ 拆开」），旧 diamond/twin 单元样式载入时自动迁移为胶囊；③ README 称单文件版「数据存 IndexedDB」，实况 file:// 下用 localStorage；④ tests/ux-browser-conflicts.md §15 记 F-10「顺延不做」，实况触摸长按拖拽排序已在轮 14b 落地。

## 附录 B · E2E 用例汇总

共 **97 条**建议用例：S1×20、S2×15、S3×17、S4×13、S5×14、S6×10、S7×8；其中边界/异常分支用例约 40 条。覆盖方式建议沿用 lab 既有仪器：`page-l0/l1/l2`、`__fs.snapshot()`（状态断言）、`dispatchTouchEvent`（触摸管线）、下载 file:// 用 `page.goto('file://…')` 上下文单独覆盖（S6）。

**风险最高的 10 个边界情况**（建议优先落测）：
1. 播放中删队形/重排/拖块（S3/S2 交界）：播放状态与时间轴块的一致性（现依赖「先暂停」防护）。
2. 编辑锁（查看模式）下触摸端舞台手势全部禁用（含平移/捏合），现场解锁唯一入口是「✏ 编辑」/E 键——误触与解锁 discoverability。
3. 下载版配乐不持久：重开项目音频通道（`（重新选择文件）`）与含乐导出兜底。
4. 当前在线入口 HTTP → SW 不注册，断网完全不可用（渠道承诺与实况差距）。
5. 撤销栈 60 上限 + 打开/导入清栈：长编排会话的撤销预期管理。
6. 导入损坏/恶意文件与深链 4 类失败路径：toast 明确、不 crash、不覆盖既有项目。
7. 合并替换语义（一人已属单元时再合并=旧绑定静默解除）与 merges 帧级不跨帧——艺术意图 vs 数据实况差。
8. 多选/编组选择在切换队形帧时清空：跨帧编辑工作流的选择丢失。
9. Safari Cmd+1..9 保留键：编组快捷键静默失效且页面被切走（唯一缓解=文案引导）。
10. BPM/首拍标定错误=整条时间轴错位：点拍 2.5s 超时重置、3 次起算的边界与「试听」引导。
