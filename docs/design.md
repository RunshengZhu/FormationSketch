# Formation Studio（暂名）设计方案

> 舞蹈队形编排与音乐对齐 · 纯 Web 双端（移动/桌面）· 以 ArrangeUs 功能为蓝本，针对**体育舞蹈队列舞**特化
> 状态：设计稿（实现待启动）｜ 调研依据见 `docs/research-arrangeus.md`

## 1. 产品定位

- **一句话**：把队列舞/群舞的队形搬进浏览器——拖出来的队形、按 8 拍对齐音乐、动起来回放、导出给全队。
- **目标用户**：体育舞蹈（国标舞）队列舞队伍的教练/队长；兼顾群舞、啦啦队、行进乐队等。
- **核心差异化**：
  1. **舞伴（Couple）一等公民**：男女双人作为整体流动单位建模，可拆可合；
  2. **节拍时间线**：BPM + 8 拍网格，队形时长按拍计，吸附对齐音乐；
  3. **纯 Web、免安装、免费、本地优先**：数据存浏览器 + 文件导入导出，无账号无订阅。
- **非目标（本版本不做）**：账号/云同步、实时多人协作、3D 动捕、移动原生 App。

## 2. 核心概念与数据模型

```jsonc
// 项目文件 .formation.json（导出/导入、localStorage/IndexedDB 持久化）
{
  "version": 1,
  "meta": { "title": "2026队列舞《蓝色多瑙河》", "team": "", "createdAt": "...", "updatedAt": "..." },
  "stage": {
    "widthM": 12,            // 舞台宽（米），队列舞标准场地约 12×16
    "depthM": 16,            // 舞台深（米）
    "audience": "bottom",    // 观众方向 bottom/top/left/right（决定"面向观众"的朝向基准）
    "gridM": 0.5, "snap": true,
    "backstageM": 2,         // 四周后台区（米），首尾队形可站人
    "bgImage": null          // 背景图 dataURL（可选）
  },
  "audio": { "name": "waltz.mp3", "durationSec": 181.2,
             "bpm": 120, "beatsPerBar": 4, "firstBeatSec": 0.32,
             "storage": "idb:audio/<projectId>" },   // 音频 Blob 存 IndexedDB，项目 JSON 不内嵌
  "dancers": [
    { "id": "d1", "name": "张伟",  "short": "1M", "role": "M", "color": "#3b82f6" },
    { "id": "d2", "name": "李娜",  "short": "1F", "role": "F", "color": "#ec4899" }
  ],
  "pairs": [ { "id": "p1", "leader": "d1", "follower": "d2" } ],  // 舞伴；role=M 为引带，F 为跟随
  "formations": [
    { "id": "f1", "name": "开场横排", "color": "#22c55e", "note": "第1个8拍亮相",
      "pairLocked": true,             // 本队形内舞对是否整体编辑（队列舞=true，单人段=false）
      "positions": {
        "d1": { "x": 4.0, "y": 8.0, "facing": 180 },  // 米；facing=度，180=面向观众
        "d2": { "x": 4.6, "y": 8.0, "facing": 0 }     // 跟随者面向引带者
      } }
  ],
  "timeline": {
    "blocks": [ { "formationId": "f1", "holdBeats": 16, "travelBeats": 8 } ],
    // 每个队形块 = 到达后的保持拍数 + 进入下一队形的移动拍数；块起点由累加推算（与 ArrangeUs 同机制）
    "countInBeats": 8, "metronome": false, "playSpeed": 1.0
  }
}
```

**坐标系**：舞台左上角为原点，向右为 +x、向下为 +y，单位米；渲染时按舞台比例自适应画布。
**时间轴换算**：`secPerBeat = 60 / bpm`；音乐时刻 = `firstBeatSec + beat * secPerBeat`；无音频时用内部时钟按默认 BPM 走。
**朝向**：默认跟随者面向引带者、引带者朝行进方向；提供"全部面向观众/面向圆心"批量操作。

## 3. 功能规格

### P0 —— 首个可用版本（简洁但功能全面）

**A. 项目管理**
- 项目库页：卡片列表（标题+队形缩略图）、新建向导（人数、男女比例、舞对数）、重命名/删除/复制
- IndexedDB 自动保存（每次编辑防抖落盘）；导出/导入 `.formation.json`（不含音频）；音频文件单独关联（重新选择即可）

**B. 舞台与舞者**
- 舞台画布（Canvas 2D）：按米缩放、网格、后台区底纹、观众方向标注、中心线；舞台尺寸/后台可设；背景图上传
- 舞者：圆点 + 简称，男蓝/女粉（角色色可改）；增删改、Crew 名册（姓名列表复用）
- 朝向：每个位置可单独设朝向（拖动点上的方向把手或输入角度）

**C. 舞伴系统（差异化核心）**
- 名单页组对/拆对（男+女=一对，可一男多女等非常规组合手动指定）
- 队形画布：舞对间画细连线；`pairLocked` 队形中**拖一动二**（保持相对偏移整体平移，按 Shift/开关可单独拖）；单人段队形解除
- 舞对级操作：以舞对为单位换位、镜像（男女位置对调 + 全队镜像）、选中一对 = 两点同选

**D. 队形编辑**
- 队形序列：缩略图列表（左栏/移动端横滑条），新建（复制上一个）、重命名/颜色/备注、删除、拖拽排序、点击切换
- 快速队形生成器：横排、双横排、竖排/纵列、圆、双圆、V 形、斜线、菱形、半圆——**按舞对**（一对占一槽）或**按单人**两种粒度生成，舞者就近映射（同 ArrangeUs Preset 机制）
- 整体操作：组旋转（滑杆/快捷键）、水平/垂直镜像、水平/垂直等间距、两人换位、复制/粘贴位置
- 选择：点选、追加点选、框选、全选、按角色选（所有男/所有女）、按舞对选
- Ghost：显示上/下队形半透明位置与虚线运动路径（可开关）

**E. 音乐对齐与回放**
- 音频上传（objectURL + Blob 入 IndexedDB），波形渲染（Web Audio 解码峰值）
- BPM 设置：手动输入 + **Tap Tempo**；首拍偏移（拖动节拍网格对齐波形）；每小节拍数（默认 4，8 拍高亮）
- 音乐时间线：队形块（保持段）+ 过渡块（移动段），拖块边缘调时长、Ripple 开关、**边缘吸附节拍**、块上显示小节号/8拍数
- 回放：播放/暂停/停止、从选中队形播、循环区间、0.5x–2x 变速；以 `audio.currentTime` 为主时钟；队形间位置线性插值 + 缓动，朝向角度最短路径插值；节拍器可选（节拍闪灯 + 咔哒声）
- 编辑模式（不挂音乐）下：逐队形预览过渡动画（默认时长可配）

**F. 导出**
- PNG（当前队形截图）；PDF 打印（每队形一页：缩略图+备注+小节标注，浏览器打印）
- P1：带音乐 MP4（canvas.captureStream + MediaRecorder + 音频混流）

**G. 体验基础**
- 撤销/重做（快照栈，≥50 步）；键盘快捷键（空格播放、Cmd+Z、方向键微调、D 新队形、G 网格吸附…）
- 响应式：桌面三栏 + 底部时间线；移动端舞台全屏 + 底部 Tab（队形条 / 音乐 / 列表抽屉）；触摸拖动、双指平移缩放画布

### P1（增强）
- 曲线过渡路径（每舞者 1 个贝塞尔控制点）；队形预设库自存；道具（矩形/文字）；标签与归档；伪 3D 透视预览；PWA 离线 + 添加到主屏；多项目备份合并导出

### P2（远期）
- 实时协作（CRDT）；自动 BPM 检测（能量自相关初估 + 手动校准）；排练视频叠加对照；按舞者私人视图分享链接（需后端）

## 4. UI / UX 设计

**桌面（≥1024px）**

```
┌─────────────────────────────── 顶栏: 项目名 | 编辑/音乐 模式 | 撤销↺ 重做↻ | 保存状态 | 导出 ───────────────────────────────┐
├──────────┬────────────────────────────────────────────────┬───────────────────────────┤
│ 队形列表  │                 舞台画布 (Canvas)                │  属性面板                  │
│ 缩略图    │   网格/后台区/中心线                              │  · 选中舞者/舞对: 姓名/颜色/朝向 │
│ +新建     │   舞者圆点(男蓝女粉)+简称+朝向                    │  · 队形: 名称/颜色/备注/pairLock│
│ 拖拽排序  │   Ghost + 虚线路径                               │  · 舞台: 尺寸/网格/背景/观众方向│
├──────────┴────────────────────────────────────────────────┴───────────────────────────┤
│ 播放条: ⏮ ▶/⏸ ⏹ | 速度 | 循环 | 节拍器 | 当前队形 x/y | 小节:拍 指示                                          │
│ 时间线: [编辑模式]队形 pills ｜ [音乐模式] 波形 + 队形块/过渡块 + 节拍尺 + 播放头 (拖拽边缘/吸附/Ripple)            │
└────────────────────────────────────────────────────────────────────────────────────┘
```

**移动端（<1024px）**：舞台全屏；顶部精简工具（模式、撤销、导出）；底部三 Tab：`队形`（横滑缩略图 + 快捷新建）、`音乐`（时间线全宽 + BPM/Tap 面板）、`更多`（列表/设置/导出抽屉）。长按舞者 = 多选；双指 = 平移/缩放画布；双指旋转所选组（P1）。

**关键交互**（继承 ArrangeUs 验证项）：拖动释放自动吸附网格；拖到后台区允许（上下场）；Ghost/路径默认开；音乐模式块边缘拖拽 + Ripple；队形生成后自动进入"就近映射"预览可撤销。

## 5. 技术架构

**原则：零构建、零运行时依赖的纯前端**（可 `python3 -m http.server` 直接跑，也可挂任何静态托管；后续如需复杂度再迁移 Vite/TS）。

```
formation-studio/
├── index.html            # 单页壳 + 响应式布局骨架
├── css/style.css         # 移动优先 + 桌面断点
├── js/
│   ├── main.js           # 启动、模式路由、事件绑定
│   ├── store.js          # 单一状态树 + 订阅 + undo 快照栈 + 持久化防抖
│   ├── model.js          # 数据模型/序列化/迁移/ID
│   ├── stage.js          # 舞台 Canvas：渲染 + 命中测试 + 拖拽/框选/吸附/ghost
│   ├── timeline.js       # 音乐时间线：波形、块、节拍尺、播放头、ripple
│   ├── player.js         # 回放引擎：时钟、插值、缓动、循环
│   ├── audio.js          # 音频加载/解码/播放/节拍器/Tap Tempo
│   ├── shapes.js         # 队形生成器（横排/圆/V…）+ 镜像/旋转/对齐
│   ├── export.js         # PNG / 打印 PDF / JSON 导入导出
│   └── ui.js             # 面板/列表/抽屉/toast/快捷键
├── docs/                 # 调研与设计文档
└── README.md
```

- **渲染**：Canvas 2D，每帧按需重绘（脏标记）；devicePixelRatio 适配高清屏。
- **状态**：`store` 集中管理，`history` 用结构快照（项目数据 < 100KB，快照开销可忽略）。
- **存储**：IndexedDB 两个 store——`projects`（JSON）、`audio`（Blob）；导出 JSON 不含音频。
- **音乐同步**：回放以音频时钟为准，`beat = (t - firstBeatSec) / secPerBeat`，渲染循环 rAF 采样；无音频用 `performance.now()` 虚拟时钟。
- **双端**：同一 DOM/CSS 栅格自适应；触摸与鼠标事件统一走 Pointer Events。

## 6. 里程碑

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| M1 | 项目库 + 舞台/舞者/队形编辑 + 生成器 + 舞伴系统 + 本地保存 | 能建 8 对舞者项目、摆 5 个队形、拖一带一、刷新不丢数据 |
| M2 | 音乐对齐：上传/波形/BPM/时间线块/同步回放/变速/循环 | 上传 mp3 设 BPM 后，块边缘吸附节拍，播放队形变换与音乐节拍对齐 |
| M3 | 导出（PNG/打印 PDF/JSON）+ Ghost/路径 + 撤销重做 + 快捷键 | 三种导出可用；误操作可撤销 |
| M4 | 移动端适配打磨 + 节拍器 + 单人/双人段切换细节 | 手机浏览器完成全流程（建队形→对音乐→回放→导出） |

## 7. 风险与取舍

- **音频大文件**：不内嵌 JSON、存 IndexedDB Blob；导出默认不含音频（分享 JSON 轻量，音乐各自持有——与 ArrangeUs 一致）。
- **波形性能**：解码后预计算 ~2000 个峰值桶，时间线只画桶。
- **舞对拆合的复杂度**：用"队形级 pairLocked 开关"把问题局部化——队列舞 90% 场景是整体流动（锁定），单人段单独解除，避免全局模式切换的心智负担。
- **零依赖的代价**：无现成 UI 组件，界面保持朴素（系统字体 + 少量 CSS）；换来的是零安装、可离线、代码可读易改。
